# Epistemic Hive Visual Lock v0.1

Status: design reference only. This package is not production code and is not wired into Vite navigation.

## Locked narrative

Synthetic harness -> real-model pilot -> same-world replication -> multi-world testing -> geometric hives -> archived replay.

The site is a scientific observatory for the evolution of an experiment. It is not a dashboard, a bee-themed website, or a collection of disconnected cards.

## Reference frames

- `01-home.html`: Home constellation and compact evidence strip.
- `02-exp002.html`: EXP-002 continuous Pilot -> Gate 2A -> Gate 2B spine.
- `03-gate2a.html`: W01 core with subordinate run markers for Set 001 and Set 002.
- `04-gate2b.html`: Two independent SVG-backed hives, Generalization and Stress.
- `05-replay.html`: Protected replay stage with topology, root, event, and evidence rail.

Reference viewport sizes: 1440 x 900 desktop and 390 x 844 mobile.

## Visual tokens

The package preserves the production visual DNA: dark graphite, Orbitron display type, Chakra Petch body type, mint structural light, warm evidence accents, thin geometry, and restrained glow. Semantic aliases are defined in `visual-lock.css`; condition colors are not quality rankings.

## Composition locks

- Home uses a geometric research constellation, not a replay or KPI grid.
- EXP-002 is a single continuous research spine.
- Gate 2A visually prioritizes one W01 configuration and treats 15 markers as runs.
- Gate 2B keeps Generalization and Stress as independent clusters.
- Hive cells use SVG-backed faceted geometry and distinguish misleading, trajectory difference, and final difference states.
- Replay preserves A/B/C topology, E1, archived event evidence, condition modes, and timeline semantics.
- Mobile order is copy -> visual -> summary, with no hover-dependent information.
